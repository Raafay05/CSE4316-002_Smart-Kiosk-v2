# Project Requirements

1. **Lab Directory (API-Driven)** - Pulls live lab data from the provided API and renders each lab as a card (name, supervisor); auto-refreshes with caching and graceful fallback if the API is down. We already have an in-use CSE App which has the lab directory, you will be introduced to the team and pull the data from there.
2. **Work Order Requests** - Unified form for temperature, cleaning, and repair requests; auto-routes to the right staff with status tracking and email confirmations.
3. **Voice Assistant** - Hands-free, accessible interaction for navigation, upcoming events, and lab/professor/advisor lookup using speech-to-text and output audio instruction to user.
4. **Events & Announcements Board** - Displays upcoming department events, seminars, and alerts from a calendar feed.
