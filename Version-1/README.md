# Project Requirements
1. Room Reservation System for ERSA
2. Supply Request System for ERSA
3. Automated Email System for Requirements (1) & (2)
4. Interactive Map for ERSA & ERB
5. Secure User Login for ERSA
6. Panel for CSE Announcements & Banners
7. Admin Dashboard
8. Website for Remote Access (Mobile Compatible)
9. Reliable Auto Startup after Reboot
10. Kiosk Mode to keep Users on the Kiosk System

Use this directory as a reference and research guide to gain a better understanding of the project.
