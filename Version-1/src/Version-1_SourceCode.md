# Smart Kiosk v1.0 Source Code

Summarize main components, functionality, and purpose of each file in this ReadMe for easier reference.

There are 3 folders, `kioskguys-erb-kiosk-main`, `kioskguys-main`, `kioskguys-Online-Deployment-Branch`.

Each contain source code, and my assumption is that they are for specific purposes and only work for that purpose.

1. `kioskguys-erb-kiosk-main` - Might be set up for an ERB kiosk that allows user access to the building.
2. `kioskguys-main` - Main (finalized) source code (probably best for this repository directory).
3. `kioskguys-Online-Deployment-Branch` - Probably best to run on our local machines and perform changes, tests, and finalize for the kiosk.
